# My Website

A simple static website.

## Files

- `index.html` — Home page (the entry point Netlify looks for)
- `about.html` — About page
- `contact.html` — Contact page
- `style.css` — Styles for all pages
- `script.js` — JavaScript
- `.gitignore` — Files Git should ignore

## Local preview

Just double-click `index.html` to open it in your browser.

## Deployment

This site is deployed to Netlify, connected to this GitHub repository.
Any push to the `main` branch triggers a new deploy automatically.
